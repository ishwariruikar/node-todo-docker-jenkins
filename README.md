Project Title
Node.js To Do Application with Docker and Jenkins CI CD
Project Overview
This project demonstrates how to build and deploy a Node.js To Do application using Docker and Jenkins. The goal of the project is to understand how continuous integration and continuous deployment work in a DevOps environment. The application is containerized using Docker and the build and deployment process is automated using Jenkins.
Objectives
The main objective of this project is to learn how to automate the application build and deployment process. It also helps in understanding how Docker containers work and how Jenkins pipelines are used in DevOps workflows.
Technologies Used
Node.js for building the application
Docker for containerizing the application
Jenkins for automating build and deployment
Git and GitHub for version control and code management
Project Workflow
The source code is stored in a GitHub repository. Whenever changes are pushed to the repository, Jenkins triggers a pipeline. Jenkins then builds the application and creates a Docker image. The Docker container is then used to run the application. This process demonstrates an automated CI CD workflow.
Features
Simple To Do application built with Node.js
Docker container used to package the application
Jenkins pipeline used for automated build and deployment
Version control using GitHub
Learning Outcome
Through this project I learned how to integrate Docker with Jenkins, how CI CD pipelines work, and how containerized applications can be built and deployed in a DevOps environment.
